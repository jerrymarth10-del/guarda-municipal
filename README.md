# JR Gabaritando Provas - SaaS Premium

## O que vem pronto
- App premium em HTML/CSS/JS
- Área do aluno com onboarding, aquecimento, técnica, simulado e resultado
- Área admin com CRUD de questões
- Importação e exportação JSON
- Dashboard com histórico local
- Pronto para GitHub + Vercel

## Como publicar
1. Suba os arquivos no GitHub
2. Importe o repositório no Vercel
3. Faça o deploy

## Observação importante
Esta versão funciona sem backend e salva dados no navegador (localStorage).
Para transformar em SaaS multiusuário real, conecte:
- autenticação
- banco de dados
- permissões de acesso

Backends recomendados:
- Supabase
- Firebase
- Node + PostgreSQL
